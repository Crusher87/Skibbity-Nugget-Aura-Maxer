### Implementation notes
- *Curtis: OK?* rows shipped as recommended: Distracted Boyfriend's echo is allowed under Sigma Slam; PRECISION, TEMP_CLICK_MULT and echo burns are refused (card kept, toast "The nugget is busy!") during a boss or off the Sauces tab. Blocked cards show greyed in the bar (`.blocked`), which re-renders on boss start/end, tab switch and Field change.
- Body filter: `filter: var(--f-theme,) var(--f-giga,) var(--f-retro,) var(--f-blur,) var(--f-scramble,)` — one variable per source (the table's single `--f-burn` became `--f-retro` / `--f-blur` / `--f-scramble` so AYB and Dentist can be on at the same time), and **empty fallbacks** instead of `brightness(1)` etc., so with nothing active body has no filter at all (an identity filter would make `body` the containing block of every fixed element and add a full-page filter layer all the time). Dentist's `blur` param still sets the amount (`--fx-blur`).
- `getBinderStats().bigNugget` is Big Chungus's `p.scale` (1.5), used as the base scale in `applyNuggetTransform()`.
- `awardKek` also covers `collectKekCoin` (nugget coins), so every Kek grant goes through it; the `kekDoubleCount` 2× still applies only there. The debug +50 cheat is left as is.
- Chase targets now move in px/s (`speed × 60`), with frame `dt` capped at 0.1 s so a stalled tab can't teleport them.
