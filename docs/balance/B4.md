# B4: Burn Commons numbers (B4a / B4b / B4c)

**Type:** number and text tuning. **Needs Curtis's OK.** A quick "ok" per table is enough.

**Prerequisites:**
- B1: the D6 `easPerClick` / `capEAS` path, the buff list, and one-shots on base EAS.
- B2: the activation gate and the burn bar above the boss.

**Budget:** Common 30–45 EAS (up to 67.5 with a real downside), Kek ≤ 5.

**How the numbers are computed:**
- "After" uses the `tools/card-sim.js` formulas, plus the D6 term `min(capEAS, easPerClick × qualifying clicks)`.
- Reference states: Early, Mid, Late.
- Click cards: skilled = 6 cps, casual = 3 cps. Skill cards: skilled / casual = 90% / 50%.
- One click = 0.025 / 0.069 / 0.052 EAS.
